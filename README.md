## How to use this hub

1. Start with the [syllabus outline](docs/SYLLABUS.md) and the official GATE 2027 website to confirm the current syllabus.
2. Pick **one or two** note styles and stick with them. More notes do not mean better preparation.
3. Use short notes and last-minute notes for revision, and main notes for first-time learning.
4. Solve the subject-wise questions from [`pyqs/`](pyqs/) after finishing each subject.

## Things to keep in mind

- These materials come from different years and editions. Some may not match the latest syllabus, so always check the official GATE 2027 brochure.
- `notes/ribhu/Complete RoadMap for GATE CSE 2022.pdf` is a roadmap written for GATE 2022. Treat it as general strategy, not a current plan.
- Software Engineering and the extra Ribhu "IIT Interview" material go beyond the GATE CS syllabus.
- Notes can contain errors. Verify important formulas and facts against a standard textbook.
